# 3943B IF/IQ to CAP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Convert 3943B UDP IF/IQ `.iqraw` files into the existing local `.cap` format.

**Architecture:** Add a focused parser for 3943B IF packets that scans for the big-endian `0x000EB200` packet magic, uses the packet byte length from the common header, strips each packet header, decodes little-endian `int16 I/Q` pairs, and writes samples through the existing CAP writer. Keep raw capture unchanged unless the smoke tool is explicitly given a CAP output path.

**Tech Stack:** C++17, Qt Core, Qt Test, existing `UsrpDeviceService::writeCapFile()`, existing `CapProbeService`.
