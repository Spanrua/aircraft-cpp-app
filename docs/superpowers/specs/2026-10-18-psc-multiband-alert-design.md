# PSC 多档宽带预警设计

## 目标

将现有仅针对约 20 MHz 占用带宽的 PSC 宽带预警扩展为三档规则，并同时适用于实时扫频和 CSV 离线逐帧回放。

## 预警规则

| 类型 | 实际占用带宽（含边界） |
| --- | --- |
| 10M | 8–12 MHz |
| 20M | 16–24 MHz |
| 40M | 32–48 MHz |

仍沿用当前高电平 bin 分段、命中阈值和连续两帧确认机制。一个分段只要落入任一规则即可确认预警；三段范围不重叠，因此类型唯一。

## 数据与检测

`PscWidebandAlertDetector` 将规则定义为小型值对象/规则表，而不再只保存一对最小、最大带宽。确认告警携带规则类型标签（`10M`、`20M` 或 `40M`）及现有频段、中心频率、峰值、连续帧数与频率匹配容差。

跨帧匹配仍以现有中心频率容差工作。类型不同的候选不应合并为同一条历史告警；同类型、频率在双方容差内的候选继续合并。

## 界面与回放

`SweepPage::appendPscFrame` 保持为实时与 CSV 回放的共同入口。现有持久横幅、橙色瀑布图频段和候选表继续复用：

- 横幅显示类型，例如“疑似无人机宽带信号（40M）”。
- 候选表保留实际带宽，确认状态显示“告警·10M/20M/40M”。
- 多个确认告警同帧出现时，仍选择峰值最高者更新当前横幅与瀑布图。
- 新扫频、新回放和重置仍清除检测状态、横幅、叠加层和历史活动。

不增加声音、弹窗或新的采集行为。

## 验证

服务测试覆盖每档上下边界接受、档间空白带宽拒绝、连续两帧确认、类型标记及类型不同不合并。UI 测试覆盖三档状态文字和 CSV 逐帧回放至少一档告警；现有 20M 回归测试必须继续通过。
