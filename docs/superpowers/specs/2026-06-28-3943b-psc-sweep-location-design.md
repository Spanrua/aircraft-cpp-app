# 3943B PSC 扫频定位设计

## 概要

在数据采集之前新增一个 **扫频定位** 工作流页面。操作人员使用 3943B 的 PSC 多频段全景扫描模式，通过实时瀑布图/时频图寻找疑似无人机信号频点，然后确认候选频点，并传递给现有采集页用于 IQ 采集。

扫频页不得输出原始 IQ 数据或 `.iqraw` 文件。该页面只接收 PSC 全景扫描数据，并渲染为供专家研判的时频视图。

## 工作流

主工作流顺序调整为：

1. 扫频定位
2. 数据采集
3. 预处理
4. 数据集
5. 训练
6. 识别

扫频页作为第一个页面。当前采集页顺延为第二步。用户在扫频页确认候选频点后，将选定频率写入采集参数，或在用户切换到数据采集页时让该频率可用。

## 仪器命令

使用厂家多频段 PSC 模式：

- `FREQ:MODE PSC`
- `SWE:MODE:SPE SENS`；v1 固定使用灵敏度优先
- `TRAC:UDP:TAG:ON "<pc_ip>",<port>,PSC`
- `TRAC:UDP:FLAG:ON "<pc_ip>",<port>,"VOLT:AC","FREQ:RX","FREQ:HIGH:RX","OPT"`
- `PSC:SEGM:CONF "<start>,<stop>,<step>;..."`
- `INIT`

停止和清理使用 `ABORt`、`*CLS` 和 `TRAC:UDP:DEL ALL`。

该扫频流程不得配置 `IF`、`IFPAN`、`AUD`、`TRAC:IQ:DATA:REP` 或 `SYST:IF:REM:MODE SHORT`。

## 界面设计

页面分为三个工作区域：

- 左侧：3943B resource、本机 UDP 目标、多频段扫频表格，表格包含起始频率、终止频率和 RBW/step。
- 中间：实时瀑布图/时频图，横轴为频率，纵轴为时间，电平映射为颜色。
- 右侧：简单峰值候选和专家操作，包括选择、锁定、写入采集页、继续扫频。

默认候选生成方式为 **简单峰值检测 + 专家确认**。软件列出超过背景/阈值规则并跨帧持续出现的频点。v1 不做无人机信号分类。

## 服务设计

新增 PSC 专用接收/解析路径，不把 PSC 当作 IQ 文件处理。解析器将收到的 UDP PSC 包转换为包含频率 bin 和电平值的帧。扫频会话服务负责 UDP 接收器、PSC 命令序列、停止清理、帧缓冲和候选提取。

## 测试

先添加服务测试，覆盖：

- PSC 命令生成只包含 PSC tag/flag，并排除 IF/IQ 命令。
- 多频段配置能正确格式化厂家 `PSC:SEGM:CONF` 字符串。
- 停止命令会中止扫描并清理 UDP 路径。
- PSC 解析器能接收代表性数据包并输出频率/电平 bin。
- 候选提取会提升持续峰值，并忽略单帧尖峰。

添加 UI 测试，覆盖工作流顺序、新扫频页存在，以及已确认候选频点能够暴露给采集流程。

## 假设

- 目标 UI 仍为桌面 Qt Widgets。
- 界面语言为中文。
- 主要输入方式为鼠标和键盘。
- PSC 数据包字段遵循 3943B 手册的通用头：魔数 `0x000EB200`、大端字段、PSC 包头值 `1201`，以及电平/频率标志。
- 硬件执行保持现有安全策略：尽可能先检查/dry-run，并始终提供明确的停止/清理路径。
